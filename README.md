# 🚀 Como executar

Clone o projeto

```bash
git clone https://github.com/SEU-USUARIO/portfolio.git
```

Entre na pasta

```bash
cd portfolio
```

Instale as dependências

```bash
npm install
```

Execute

```bash
npm run dev
```

Abra

```
http://localhost:3000
```
