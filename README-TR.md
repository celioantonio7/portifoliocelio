## 📋 <a id="sobre"></a> Sobre

Este é o meu portfólio pessoal, desenvolvido para apresentar minha trajetória como desenvolvedor Full Stack, minhas tecnologias, projetos e experiências.

O projeto foi inspirado em interfaces modernas e experiências imersivas, priorizando animações suaves, alta performance, design responsivo e uma arquitetura limpa. Além de representar meu trabalho como desenvolvedor, ele também destaca meu principal projeto, o **HappyCash ERP**, uma plataforma SaaS para gestão empresarial.

## ✨ <a id="recursos"></a> Recursos

- **Animações Modernas** com Framer Motion.
- **Scroll Suave** para uma experiência fluida.
- **Tema Claro e Escuro** com troca dinâmica.
- **Suporte a Múltiplos Idiomas**.
- **Design Responsivo**, adaptado para desktop, tablet e smartphone.
- **Arquitetura Limpa** e componentes reutilizáveis.
- **Alta Performance** utilizando React, Vite e TypeScript.

## 🛠️ <a id="tecnologias"></a> Tecnologias

- **React** — Biblioteca para construção da interface.
- **TypeScript** — Tipagem estática para maior segurança.
- **Vite** — Build tool moderna e extremamente rápida.
- **Tailwind CSS** — Framework CSS utilitário.
- **Framer Motion** — Animações e microinterações.
- **Shadcn/UI** — Componentes modernos e acessíveis.
- **Lucide React** — Biblioteca de ícones.
- **React Router** — Gerenciamento de rotas.

## 🚀 <a id="instalacao"></a> Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/SEU-PORTFOLIO.git
```

Entre na pasta:

```bash
cd SEU-PORTFOLIO
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Abra no navegador:

```
http://localhost:5173
```
